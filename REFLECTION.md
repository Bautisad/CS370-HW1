Throughout homework one, the artificial intelligence that we used had its ups and downs. Although there were not many downsides compared to the upsides, surprisingly it was easy to work with. Understanding the assignment is a must, not something you can just rely on Claude for.

One major upside is the way Claude knows what context the program is going to be. A mention of red and black trees allows the program to automatically assume what code is needed. The ability to recommend the necessary methods needed for the program to start is mind-boggling. I also like that the idea of just telling Claude what to plan for and telling me helps me figure out problems before they even happen. 
	
The downside of the agent is that it creates laziness and always makes you think you and it are right all the time. I think it promotes laziness is due to the fact that you can just upload the spec sheet and have it do the work for you is crazy. This allows you to bypass learning concepts that might be valuable for you. By starting the habit of reading the requirements, understanding the spec sheet, and knowing what the program is doing, you can counter that laziness. Another downside is that the agent thinks you are right all the time. If I do not verify the information or plan it gives me, then it might introduce bugs into the program. Also, it allows you to not understand your program at all. 

The bug that I caught was during the planning phase of the two-child deletion and value ownership. The agent wanted to copy a child during deletion, but it was going to create a node that could be freed twice. If I let Claude do its thing, it would have introduced memory leaks.
